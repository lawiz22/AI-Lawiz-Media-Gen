# Screenshot Capture Guide

Save the final PNG screenshots in this directory. The main README already contains commented image tags for these exact filenames.

## Capture Standards

- Use a `16:9` window at `1600×900`, `1920×1080`, or a similar size.
- Keep one visual theme and the same project name across all captures.
- Use realistic source media and completed results rather than empty states.
- Hide API keys, email addresses, local paths, filenames containing personal information, and private Library content.
- Close modals unless the modal is the subject of the screenshot.
- Avoid cursor hover effects, clipped menus, loading states, and error banners.
- Export as PNG and keep each image reasonably compressed for GitHub.

## Shot List

1. `01-image-generator.png`: Show the complete Image Generator workflow and at least one strong generated image.
2. `02-prompt-providers.png`: Open Prompt from Image, select Ollama, and keep the three provider buttons and model list visible.
3. `03-magic-prompt-soup.png`: Use three visibly different source prompts, creativity near `1`, and show the transformed colored result.
4. `04-character-generator.png`: Include the source character, reference controls, and a coherent result grid.
5. `05-ltx-director.png`: Build a timeline with multiple clips, distinct prompts, images, durations, and audio.
6. `06-advanced-tts.png`: Show two or more named characters with photos, voice selections, emotions, and dialogue lines.
7. `07-model-library.png`: Select a visually interesting model or LoRA so its preview and metadata are readable.
8. `08-voice-recorder-library.png`: Show a completed recording with waveform/meter information and its reusable Library entry.

After adding each image, find its matching line in the root README and remove the HTML comment markers to publish it.
