LAWIZ MEDIA GENERATOR - COMFYUI REQUIRED NODES
================================================

Audit date: 2026-09-05
Source audited: every class_type used in constants.ts,
services/comfyUIService.ts, services/characterAnglesWorkflow.ts and
services/ltxDirectorWorkflow.ts, including dedicated feature workflow builders.

SUMMARY
-------

Lawiz currently references 97 distinct ComfyUI node classes.

- 58 are included in a current ComfyUI installation (core + comfy_extras).
- 39 are supplied by external custom-node packs.
- The complete feature set uses 24 external repositories when the LTX Director
  compatibility dependency is included.

IMPORTANT: update ComfyUI before installing custom nodes. Recent versions include
WAN, Qwen Image/Edit, FLUX, LTX audio/video and advanced sampler nodes that older
ComfyUI installations do not contain.

The easiest installation method is ComfyUI Manager:

1. Update ComfyUI.
2. Open Manager > Custom Nodes Manager.
3. Search for and install every package in the COMPLETE INSTALL LIST below.
4. Use Manager > Install Missing Custom Nodes if it is available.
5. Restart ComfyUI completely.
6. Reopen Lawiz and reconnect to ComfyUI.

For manual installation, clone each repository into:

  C:\ComfyUI_windows_portable\ComfyUI\custom_nodes

Then follow that repository's installation instructions. Prefer Manager because
packages such as Nunchaku, SeedVR2, Impact Pack and TTS Audio Suite require extra
Python dependencies or installation scripts.

WHAT THIS FILE DOES NOT INSTALL
-------------------------------

This is a node dependency list, not a model inventory. Checkpoints, diffusion
models, LoRAs, CLIP/text encoders, VAEs, SAM/Ultralytics detectors, upscale
models and SeedVR2 model weights are separate files. Lawiz reads the available
model choices from ComfyUI after the required node classes have loaded.

If a workflow reports "Node does not exist", compare the exact class name in the
error with the exhaustive inventory above, update the corresponding package,
restart ComfyUI, then reconnect Lawiz.
